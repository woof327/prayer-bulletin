# 새가족부 기도회 순서지

휴대폰으로 보는 기도회 순서지입니다. `index.html` 파일 하나로 되어 있습니다.

## 악보 넣기

1. 악보 이미지(jpg/png)를 `scores/` 폴더에 넣습니다.
2. `index.html` 아래쪽의 `SCORES` 설정에 경로를 적습니다. 한 곡이 여러 장이면 순서대로 적습니다.
3. 같은 이름의 파일을 새 악보로 바꿨다면 `SCORE_VERSION` 숫자를 1 올립니다. 그래야 예전 악보를 기억하는 브라우저도 새 파일을 받습니다.

```js
praise1: { title: "합심 · 위러브", pages: ["scores/01-합심-1.jpg", "scores/01-합심-2.jpg"] },
```

악보를 탭하면 전체 화면으로 열립니다. 두 손가락으로 확대하고, 두 번 탭하면 확대/축소, 좌우로 밀면 다음 장으로 넘어갑니다.
